# MIND ARCHIVE · 뇌구조 열람실

AI 채팅에서 OOC로 받은 JSON으로 **두 사람의 뇌구조**를 취조 파일처럼 열람하는 정적 페이지입니다.
빌드 과정 없이 `index.html` 하나로 열리고, GitHub Pages에 그대로 올릴 수 있습니다.

**https://yuuuulll35.github.io/mind-archive/**

## 구성
| 화면 | 내용 |
|---|---|
| 사건 표지 | 사건번호 · 제목 · 날짜 · 분석관 메모 |
| SUBJECT A / B | 신상 카드(사진·MBTI·사주 등), 폴리그래프 지표, **옆얼굴 뇌구조 맵**, 영역 인덱스, 파일 서랍 10칸 |
| 파일 팝업 | 뇌 영역·인덱스·서랍 탭을 누르면 파일이 팝업으로 열림. 탭이나 ← → 키로 01~10 이동, A/B 전환으로 같은 파일 비교 |
| CROSS-EXAM | 마주 보는 두 뇌, 관계 상태와 서로를 향한 시선, 서사 타임라인, 파일별 A/B 대조표 |

파일 서랍 10칸:
01 한눈에 보는 이 사람 · 02 사고/행동 방식 · 03 대인관계 · 04 좋아하는 것/싫어하는 것 · 05 연애관 ·
06 상대에 대한 생각 총정리 · 07 관계에 대한 희망/부정적 생각 · 08 앞으로의 계획과 원하는 것 ·
09 숨기고 있는 것(검은 줄을 눌러야 보임) · 10 쓸데없는 잡생각(손글씨 메모)

## 사용법
1. **OOC 프롬프트** 버튼으로 요청문을 복사해 AI 채팅에 보냅니다. 사주, MBTI, 캐릭터 설정, 서사, 관계성을 근거로 분석하라는 지시가 들어 있습니다.
2. AI가 준 답변을 **OOC 답변 넣기**에 통째로 붙여넣습니다. `NPC` / `PC`를 고르면 한 사람만, `서사`를 고르면 전체를 바꿉니다.
3. JSON이 없어도 됩니다. **편집 모드**에서 모든 글자를 눌러 바로 고칠 수 있고, 항목과 뇌 영역, 지표를 추가하거나 지울 수 있으며 사진도 넣을 수 있습니다.
4. 편집한 내용은 이 브라우저에 자동 저장됩니다. **내보내기**에서 백업 파일 저장·복사, 현재 화면 이미지 저장을 할 수 있습니다.

## JSON 형식 (요약)
```json
{
  "case": { "no": "", "title": "", "date": "", "officer": "", "memo": "" },
  "subjects": [
    {
      "id": "A", "name": "", "alias": "", "age": "", "mbti": "", "saju": "",
      "occupation": "", "role": "", "tags": [],
      "readings": [{ "label": "경계", "value": 70 }],
      "brain": [{ "label": "사건", "weight": 26, "link": "s08" }],
      "sections": {
        "s01": { "lead": "", "items": [], "quote": "" },
        "s04": { "lead": "", "pos": [], "neg": [] },
        "s02": { "lead": "", "items": [] }
      }
    },
    { "id": "B" }
  ],
  "relation": { "status": "", "a_to_b": "", "b_to_a": "", "keywords": [], "timeline": [] }
}
```
- `brain.weight`는 비율로 자동 환산됩니다(합이 100이 아니어도 됩니다). `link`는 영역을 눌렀을 때 열릴 파일(`s01`~`s10`)입니다.
- `s04`와 `s07`은 `pos`/`neg` 두 칸을 씁니다. 나머지는 `items`를 씁니다.
- 빠진 필드는 빈칸으로 채워지므로 일부만 와도 열립니다.

## 파일
- `index.html`: 페이지 골격과 대화상자
- `style.css`: 취조 파일 디자인
- `data.js`: 섹션 정의, 빈 템플릿, 샘플 사건, OOC 프롬프트
- `app.js`: 렌더링, 뇌 영역 배치, 편집, 불러오기와 내보내기

샘플 인물(서도윤, 한이서)은 모두 성인인 허구의 인물입니다.
